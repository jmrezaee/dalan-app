## What is solid

These points were confirmed in the code:

- **Secrets:** commands return flags only, never a secret.
- **Webview permissions:** only `core:default` and `dialog:allow-open`, with no fs, http or shell plugin.
- **Terminal bytes:** raw bytes over a Channel, batched at 8 ms / 64 KB, with 1 MB ack backpressure.
- **Sign-in:** every SSH path goes through one authenticated connect with host-key checks. Tunnel autostart refuses unknown keys.
- **Encryption:** Argon2id (64 MiB, t=3) and XChaCha20 with random nonces.
- **Errors:** `AppError` is `{code, message}`.
- **Terminal tabs:** kept mounted with `v-show`.
- **UI calls:** no `invoke` outside `useTauri.ts`.
- **Colours and icons:** no raw hex in components, Lucide icons only, fonts bundled locally.
- **Migrations:** 0002 to 0004 are correct, and 0001 is untouched.

## Must fix

1. **Nothing has been verified end to end.**
   - Do one manual pass in the real window against Docker sshd, starting with M1 (F01, F11, F12), then F02 to F10.
   - Until then, treat every `clone=yes` row as unverified. This is especially true for Mosh, serial, Telnet, env vars, proxy, agent forwarding, certificates, AI, logs and history. None of these ever ran against a real server, device or API.
2. **A key-type switch skips the "identity changed" block** (`src-tauri/src/known_hosts.rs:37-49`).
   - The lookup is by `(host, key_type)`, so a server that now presents ECDSA where Ed25519 was saved gets an ordinary "first time" trust prompt. This breaks hard rule 5.
   - Fix: if any key is saved for the host and none matches, return `Changed`.
3. **The AI address check can be bypassed** (`src-tauri/src/ai.rs:92`).
   - `starts_with("http://localhost")` also accepts `http://localhost.evil.com`, so the API key could go over plain HTTP to another machine.
   - reqwest also follows redirects and keeps `x-api-key`.
   - Fix: parse with `url::Url`, allow http only for loopback hosts, and use `redirect(Policy::none())`.
4. **No content security policy** (`tauri.conf.json`: `"csp": null`).
   - Injected script could use `fs_list` and `transfer_start` to read and upload local files, or point `ai_save` at its own server and then call `ai_suggest`.
   - Fix: set a strict CSP, and require the AI key to be entered again when the address changes.
5. **Tab status dots are wrong** (`app/pages/index.vue:79`).
   - Every connected tab shows "unread". Disconnected shows idle instead of red.
   - A pending prompt never shows "waiting for you", and workspace tabs get no dot.
   - The feature row is still `no`.

## Should fix

6. **"Replace saved key" is only enforced in the UI.**
   - Rust accepts any `accept:true` for a changed key.
   - "Trust once" isn't possible: `remember` is ignored, so every accept is saved (`ssh/client.rs:150-160`, `ssh/mod.rs:144-160`).
7. **Command history is stored as plain text**, and its password-prompt filter is a guess, so `mysql -pSecret` is saved as typed. Encrypt it with the vault key and filter obvious secret flags.
8. **File permissions:** `vault.db`, `logs/` and `edit-tmp/` (plaintext server files) use the default umask. Use 0700 for the folders and 0600 for the files.
9. **Changing the master password breaks old session logs:** they were encrypted with the old key. Re-encrypt them, or use a stable data key wrapped by the password.
10. **No single-instance plugin.** A second launch wipes the first one's `edit-tmp`, marks its live logs as ended and starts the tunnels twice.
11. **Agent forwarding is wider than intended.**
    - SFTP, tunnel and key-install connections also accept agent channels.
    - It forwards the whole system agent with no confirmation.
    - Fix: enable it only for interactive shells.
12. **Keyboard-interactive sign-in is missing**, so servers with 2FA or PAM prompts will fail (`ssh/client.rs:534-603`).
13. **SFTP open can survive a vault lock.** Check that the vault is still unlocked before adding the connection, and cancel pending prompts on lock.
14. **Shortcut labels are hard-coded ⌘** in about 20 places. They are wrong on Windows and Linux, and stale after a custom rebind. Render them from the user's current shortcuts.
15. **Missing architecture commands:** `tags_list` / `tag_delete`, `recent_connections` (the `connection_history` table is never written), `fs_realpath`, `snippets_move`. The orphan-secret sweep on unlock was never built.

## Spec gaps (UI)

- **Tab bar:** no ⌃Tab cycling, ⌘J switcher, middle-click close, F2 rename, drag to reorder, or drag a tab onto a tab to make a workspace.
- **Workspace:** an auto grid, not a resizable split. No ⌘⇧D, and no "Broadcasting to N" pill.
- **S10 tunnels:** the step-by-step wizard isn't used. It is a single form.
- **S18 overlays:** the terminal isn't hidden from screen readers while an overlay shows.
- **S21 SFTP:**
  - The "no access" and "SFTP isn't enabled" states just show the raw error.
  - No virtualisation for big folders, no F2 rename, no ⌘C/⌘V across panes.
- **S23 settings:**
  - Missing: post-quantum key exchange, SFTP open-with apps, local shell path, font family, default terminal theme, and the shortcut recorder UI.
  - The theme swatches use ad-hoc neutral colours.
- **Overlays:** they use `bg-black/80` (add a `scrim` token). Some sizes are hard-coded as `text-[13px]` / `text-[15px]`.
- **Conventions:**
  - Sections switch on a ref instead of pages.
  - Three components call the dialog plugin directly.
  - `RuleCard` hand-writes the tunnel state type.
  - `RuleCard` is a clickable div with no keyboard access.
- **First-run copy (S24):** drops "There's no way to recover it, so keep it somewhere safe." (`brand.md` #1).
- **Import:**
  - SSH-config import doesn't bring keys or known_hosts and doesn't follow `Include`.
  - SecureCRT is missing.
  - The import `kind` is a string, not a generated enum.
