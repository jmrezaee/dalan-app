## Still open

### Blockers (before the first release)

1. **The `v0.1.0` tag is stale.** It points at `49c3fee`, 12 commits before HEAD, with none of P21 to P25. Delete it and tag again only after the first green CI run.
2. **No GitHub remote.**
   - `origin` is a local bundle.
   - None of the CI jobs (e2e, Docker sshd, release, Pages) has ever run on GitHub.
   - `release-setup.md` is stale: it still mentions the placeholder updater key, but the real key is in place.
3. **`features.csv` is malformed.** Rows 4, 47, 59 and 94 have unquoted commas, so a CSV reader shifts their columns: row 94 reads as `yes` but is really `partial`.
   - Statuses also lag behind:
     - 53 rows are `partial`.
     - Several of those are already checked by hand: groups, drag to groups, key generate and install, SFTP actions, workspaces, broadcast, templates and multi-host snippets.
     - Some `yes` rows were never fully checked (row 30: only local tunnels; row 12; row 34; row 53).

### High

4. **Auto-reconnect revives sessions the user closed.**
   - `exit` makes Rust send `Exit` then `Disconnected` (`ssh/client.rs:1020-1023`).
   - The store schedules a retry on `disconnected` (`app/stores/sessions.ts:135-138`) and ignores `exit` (`:162`).
   - The tab also counts in the "N connections dropped" card.
5. **`hosts_shared_logins` is a password oracle** (`src-tauri/src/hosts.rs:451`). It compares decrypted passwords and returns which hosts match. Script in the page could save a dummy host with a guessed password and ask which hosts it groups with. That breaks the intent of hard rule 1.
   - Fix: compare only the username plus key or identity ids.
   - Or drop the password comparison, or put it behind entering the master password again.
6. **Privacy (outside the code).** During the hands-on look at the reference app, 12 entries from your real `~/.ssh/known_hosts` were imported into that app's cloud-synced vault, and they are still there (`field-report-2026-11-06.md:206,220,287`). Delete them in that app by hand.
7. **Clean room.** `replica/field-report-2026-11-06.md` says it copies no UI text, but it quotes the reference app's strings verbatim:
   - placeholders and prompts (lines 24, 28, 30, 154)
   - connection screen and drop-card labels (152, 192)
   - key-type hints (233)
   - whole menus in order (260-263)

   Rewrite them as descriptions of behaviour. Dalan's own strings checked so far are original.

   **Policy point for you:** `CLAUDE.md` allows public docs for behaviour. Hands-on use of your own copy of the app goes beyond that. Either say in `CLAUDE.md` that it's allowed (behaviour only, no copied text, no data from your machine), or stop doing it.

### Medium

8. **"Try another way" uses the chosen sign-in method on the wrong hop.** `take_forced_method()` is consumed by the first `authenticate` call, which on a jump chain is the bastion, not the target (`ssh/client.rs:622`).
9. **Quick connect creates a new host on every use** (`NewTab.vue:44-52`). The `user@host:port` text never matches a saved label, and the lookup after saving ignores the port, so it can open an older host on another port.
10. **"Edit in default app" and "Open with…" can launch server files.** Files such as `.command`, `.app`, `.desktop`, `.jar`, `.exe`, `.bat`, `.sh` with the exec bit, and `.terminal` would run on your machine (`commands/sftp.rs:330`). Refuse executable types, or open them as text.
11. **Smoke findings never fixed:**
    - The first click on "…" only shows the tooltip.
    - Import silently drops an unticked jump host when the vault host has a different label (`import/mod.rs:459-467`).
    - The "8 characters" message stays after the password is fixed.
    - The "Saved." toast covers the sheet footer.
    - The file size is stale after an upload.
12. **No UI for two commands.** `fs_realpath` (the typed path should resolve `~` and `..`) and `snippets_move` (drag a snippet onto a package) exist only in Rust.
13. **Convention drift.** Vault sections, SFTP and Settings switch on a ref in `pages/index.vue` instead of being pages, and 10 components call `useTauri()` directly instead of going through a store.
    - **Recommendation:** keep the single-page shell, since terminals must stay mounted anyway, and update `CLAUDE.md` to match.
    - Move the direct `useTauri()` calls into stores.
14. **Process.**
    - P16, P17 and P18 are marked `[x]` with hand checks still open.
    - P21 is glued onto the end of P20's line in `progress.md`, and P23 is listed after P24.
    - The Notes section has no P21 to P25 lines.
    - `CLAUDE.md` "Where we are" still says P15 to P20 are next.

  - The snippet-hint "Not now" is forgotten when the panel remounts.
